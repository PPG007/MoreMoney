# T17 · 日历热力与单日明细

## 3. 页面结构

```text
列
├── 月份行：← 11月 →（16/700）
├── 星期行：一 二 三 四 五 六 日（10/400 ink_3）
├── 日历卡（padding 15、圆角 24、chart_surface）
│   └── 7×6 网格，每格 aspect 1
└── 单日明细：日期头 10/600 + 流水行（复用 T06 TxnRow）
```

## 4. 日历网格

- 周起始日取 `SettingsService.weekStart`（默认周一）；星期行与列顺序随之变化。
- 前置空白格数量 = 当月 1 日的星期偏移；总格数固定 42（6 行），不足补空格。
- 单元格：圆角 10，padding 2，`aspectRatio(1)`；日期 10/500，金额 10/400（设计 7 → 落地 10）。
- 日期数字放中上，金额放中下；金额超过 4 位时用 `¥1.2k` 缩写（≥10000 元才缩写，保留一位小数）。
- 今天：日期数字 `brand_ink` 加粗（不加背景）。
- 选中：1vp `brand_ink` 边框 + 2vp `brand_ink` 18% 外光环（用 `.border` + `.shadow` 或外层容器实现）。

## 5. 热力

- 数据：`StatsService.byDay({bookIds, memberIds, excludeBookIds, startMs, endMs})`。
- 分档：按当天金额 / 当月最大单日金额：
  - 0：无填充（透明）；
  - (0, 0.25]：`brand` 7%；
  - (0.25, 0.5]：`brand` 13%；
  - (0.5, 0.75]：`brand` 20%；
  - (0.75, 1]：`brand` 28%。
- 热力是格子背景，选中时边框优先。
- 隐藏金额：去掉热力背景与金额，只保留日期格；选中仍可查看明细，但明细金额打码。

## 6. 交互

- 月份左右切换，跨年正确；切月后默认选中 1 日（若是未来月，不允许进入）。
- 点击某天：选中该格，下方加载当天流水（`TxnDao.listByDay(bookIds, dayKey)`），按 `occurredAt` 降序。
- 单日明细头：`11月9日 周一` 10/600 `ink_2` + 右侧当天合计 `MoneyText` 10/600。
- 明细行复用 `TxnRow`；无记录显示“这天没有记账”。
- 私密锁定账本：从账本筛选中隐藏；若当月没有任何未锁定账本，显示空态。
- 默认选中的日期：今天（若今天在本月），否则 1 日。

## 7. 账本/成员筛选

- 与分类/趋势共用顶部筛选弹层（T15 提供）。
- 筛选变化后重新查询整月数据并保持选中日。

## 9. 注意事项

- 不要在 `Grid` 里嵌套可滚动 `List`；单日明细放在日历卡下方，随页面整体滚动。
- 42 格必须固定高度策略，避免不同月份页面高度跳动。
- 热力颜色用 `withAlpha(brand, x)` 计算，深浅色都要重新取 `brand`。
