## 3. 设置页

版本号读取使用 `bundleManager`（来自 `@kit.AbilityKit`）。

结构（§8.5）：

```text
标题“设置”25/700
├── 备份状态卡：图标 39 + 上次备份时间 + “去备份”迷你按钮
├── 分组“数据”
│   ├── 账本管理（row）
│   ├── 分类管理（row）
│   └── 数据与备份（row）
├── 分组“隐私”
│   └── 私密账本（row）
├── 分组“通用”
│   ├── 周起始日（右值：周一 / 周日）
│   ├── 外观（右值：跟随系统，禁用）
│   └── 关于（右值：1.0.0）
└── 版本信息 10/400 ink_3 居中
```

要求：

- 分组标签 10/700、字距来自设计（0.12em 可用 `letterSpacing(1.2)`），颜色 `ink_3`。
- 设置卡：圆角 20、`surface` 底、行 padding `11 13`、行间 1vp `line`；行图标 31×31、圆角 10、`surface_2` 底、图标 16。
- 备份状态卡：padding 13、圆角 20、渐变 `brand_wash → surface`；显示“上次备份 11月9日 15:30”或“从未备份”；点击进入数据与备份页。
- “周起始日”：点击弹 `TextPickerDialog` 或自定义弹层，选项“周一 / 周日”，写入 `SettingsService.weekStart`，影响日历与趋势周聚合。
- “外观”：固定“跟随系统”，不提供切换；点击提示“暂不支持手动切换”（Toast），行保持可读。
- “关于”：点击打开 `AlertDialog` 或底部弹层，展示应用名、版本（从 `bundleManager` 读取）、隐私说明链接文本（本地文案，不外链）。
- “私密账本”：打开 `BookManagePage` 并传 `new BookManageParam(true)`（只显示私密账本，T08 定义）；无账本时显示空态与“去创建”跳转。
- 不新增“应用锁”“隐藏金额”设置项（设计已移除）。

## 4. 数据与备份页

结构（§8.8）：

```text
NavDestination
├── PageHeader（返回 / “数据与备份”）
├── 备份状态卡：图标 41 + 标题 13/700 + 副标题 10/400 + 信息行
├── 立即备份（主按钮 46）
├── 从备份恢复（次级按钮 40）
├── 分组“导入导出”
│   ├── 导出 CSV（描述：日期、账本、成员可筛选；格式说明）
│   └── 导入 CSV（描述：覆盖前校验，错误带行号）
├── 分组“数据统计”
│   └── 4 个账本 · 1,284 笔 · 12.4 MB
└── 风险提示 10/400 ink_3：“恢复会覆盖当前数据”
```

要求：

- 备份状态卡信息行：上次备份时间、文件名、大小（若能读到）。
- 数据统计：账本数、流水数来自 DAO；数据库文件大小尽量通过 `fileIo.stat` 获取（路径以 SDK 实际为准），失败显示 `—`。
- 备份/恢复按钮在任务进行中显示 loading 并禁用。
- 导出/导入复用 T19/T20 的弹层。
- 恢复成功后刷新统计。
- 页面进入时刷新一次（`onShown`）。

## 6. 注意事项

- 设置项只走 `SettingsService`，不要在页面直接操作 Preferences。
- 版本号从 `bundleManager.getBundleInfoForSelf()` 读取，不硬编码。
- 外观固定跟随系统，不实现深色手动切换（设计未要求）。
- 数据页的“大小”不是关键指标，读不到时不要报错。
