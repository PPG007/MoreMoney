# T09 · 成员管理

> 状态：待开始 ｜ 优先级：P1 ｜ 依赖：T03、T05 ｜ 预估：1.0 人日
> 设计依据：`MoreMoney.md` 成员管理、`设计规范.md` §4.5、§7.3

## 1. 目标

实现成员的新增、编辑、默认、归档与删除。成员是本地标签，不参与品牌色体系。

## 2. 交付物

| 路径 | 内容 |
|---|---|
| `entry/src/main/ets/pages/members/MemberManagePage.ets` | 页面 |
| `entry/src/main/ets/pages/members/MemberEditSheet.ets` | 新建/编辑弹层 |
| `entry/src/main/ets/components/base/MemberDot.ets` | 复用 T05 组件 |

## 3. 入口

- 唯一入口：记一笔页 → 成员选择器弹层 → 底部“管理成员”。
- 不在设置页新增入口（设计 §8.5 已收敛）。

## 4. 实现要求

### 4.1 列表

- 页面头部：返回 34 / “成员管理” 17 / 右侧 + 34。
- 行：`MemberDot(21) + 名称 12/500 + 默认徽标 + 右侧更多（编辑/设为默认/归档/删除）`。
- 行高 52，padding `11 13`，行间 1vp `line`，卡片圆角 20。
- 已归档成员默认隐藏，底部“显示已归档”切换。

### 4.2 新建/编辑

`bindSheet` 字段：

| 字段 | 规则 |
|---|---|
| 名称 | 必填，1–8 字，去首尾空格 |
| 首字 | 自动取名称第一个字符；不可手填；emoji/英文取首字符 |
| 颜色 | 6 色可选：自己 `#2A78D6`、家人 `#C94B7B`、孩子 `#137A57`、`#6250D6`、`#E34948`、`#1BAF7A`（深浅色用 `MemberPalette` 映射） |
| 设为默认 | `ToggleRow`；同一时间仅一个默认成员 |

- 默认成员在记一笔时预选。
- 成员色存 token key（如 `self`/`family`/`child`/`c5`…），不存 hex；渲染时经 `MemberPalette` 解析。

### 4.3 删除与归档

- `countTxns(memberId)` 由 `TxnDao` 提供（可新增 `countByMember`）：
  - 有流水：只能归档；归档后不出现在记账选择器，历史流水仍显示该成员。
  - 无流水：可删除，二次确认。
- 默认成员不可删除；需先把其他成员设为默认。
- 至少保留 1 个未归档成员，否则拒绝归档/删除并提示“至少保留一位成员”。

## 5. 验收标准

| 编号 | 验收项 | 验证方式 |
|---|---|---|
| AC-1 | 从记一笔成员弹层可进入本页并正常返回 | 真机 |
| AC-2 | 新建成员后立即出现在记一笔成员选择器与首页成员筛选 | 真机 |
| AC-3 | 名称首字正确生成，颜色可切换 | 真机 |
| AC-4 | 设为默认后全局仅一个默认，记一笔默认选中 | 真机 |
| AC-5 | 有流水成员只能归档，归档后新记账不可选，历史记录仍显示该成员 | 真机 |
| AC-6 | 无流水成员可删除；最后一位成员不可删除/归档 | 真机 |
| AC-7 | 构建通过 | `devecocli build` |

## 6. 注意事项

- 成员不参与私密逻辑，不需要打码。
- 不要用姓名拼音做排序（设计未要求）；按 `sort` 升序、创建时间升序。
- 颜色变更后历史流水同步变色（因为颜色由成员表实时解析）。
