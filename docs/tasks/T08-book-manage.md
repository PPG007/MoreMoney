## 4. 实现要求

### 4.1 账本卡

- 布局：`Row { 封面 46×46(圆角 14, 图标色 16% 底, 图标 23) ; Column(名称+徽标 / meta / 进度 / 底部) ; 右侧动作 }`。
- 名称 13/700；徽标：`默认`（brand）、`私密`（warn）10/600。
- meta 10/400 `ink_3`：`本月 N 笔 · 预算 ¥3,000.00`；无预算显示 `本月 N 笔 · 未设置预算`。
- 进度条：高 5，轨道 `surface_2`，填充 `brand`；无预算时为虚线空进度（1vp dashed `line`）。
- 底部 10/400：`已用 ¥1,286.40 / 剩余 ¥1,713.60`；超支时剩余用 `expense` 色。
- 有预算：右侧“设置预算”迷你按钮（padding `5 9`，胶囊，`brand_wash`/`brand_ink`）。
- 无预算：右侧“设置预算”迷你按钮 + 底部“还没有预算”。
- 私密未解锁：金额、进度、底部全部打码；右侧显示“解锁”迷你按钮，点击弹 T13 解锁弹层；解锁后 5 分钟内正常显示。
- 点击卡片进入账本详情？v1 不设账本详情页，点击卡片打开编辑弹层；点击“设置预算”打开预算弹层。

### 4.2 新建/编辑弹层

使用 `bindSheet`（高度自适应，圆角 28）：

| 字段 | 规则 |
|---|---|
| 名称 | `TextInput`，必填，1–12 字，重复名称允许但提示 |
| 图标 | 6 选 1：`ic_book_daily/travel/family/study/work/repair`，44 方块，选中 `brand_ink` 边 |
| 颜色 | 8 个色卡（图表 5 色 + c6/c7/c8），选中打勾 |
| 私密 | `ToggleRow`；开启时调用 T13 的 `PasswordSetupSheet`，设置成功才保存 `isPrivate=true` 与 `pwdHash/pwdSalt/pwdIter`；取消则开关回退 |
| 本月预算 | 可选，元输入，最多两位小数，`MoneyUtil.parseYuanToCents`；空 = 不设预算 |

保存：

- 名称去首尾空格；空名提示。
- 新建：`sort = max(sort)+1`，非首本时 `isDefault=false`。
- 编辑：更新字段；若把私密从开改为关，必须先验证密码（T13 提供 `PrivateBookService.verify`）。
- 预算：写 `budget` 表当前月份记录（`period = DateUtil.monthKey(new Date())`），与账本保存同一事务；清空输入则删除该月预算。

### 4.3 默认账本

- 更多操作 → “设为默认”，调用 `BookDao.setDefault(id)`，刷新列表。
- 默认账本卡片显示 `默认` 徽标；全列表仅一个。
- 删除/归档默认账本时：若还有未归档账本，先要求选择新默认（弹层单选），否则拒绝。

### 4.4 删除与归档

- 更多操作：`设为默认`、`归档`、`删除`（有流水时置灰并显示说明）。
- 删除：`TxnDao.countByBook(bookId) === 0` 才允许；弹二次确认，删除后 `SnackBar` 提示（5 秒内可撤销由 T23 提供；本任务先直接删除并提示）。
- 有流水：`归档` 二次确认，文案说明“归档后不再出现在记账和统计中，历史数据保留”。
- 归档账本不出现在首页、记账选择器、预算页；账本管理页底部可切换“显示已归档”。

### 4.5 预算弹层

- 标题“设置 11 月预算”，金额输入 45 高、圆角 13、`surface_2`，前缀 `¥`。
- 快捷键：+100 / +500 / +1000（可选，若实现需在文档验收中注明）。
- 保存：>0 写入；0 或空 = 删除该月预算（等同于“不设预算”）。
- 弹层内展示本月已用金额，提示单位为元。

## 6. 注意事项

- 预算唯一来源是 `budget` 表；`book` 表没有预算列。
- 私密开关不是纯 UI 状态，必须先有密码；不要出现“私密但无密码”的账本。
- 删除账本涉及流水迁移的场景 v1 不做，只允许归档或空账本删除。
- 所有金额输入走 `MoneyUtil`，不要 `parseFloat` 后直接乘 100。
