## 5. 检查项

### 5.1 布局与安全区

- 首页 Hero 延伸至状态栏下，标题/月份不被遮挡；其他页面顶部与状态栏间距正确。
- 底部内容不被手势条遮挡；FAB、保存按钮、SnackBar 均在安全区内。
- 360vp 下：分类 4 列不挤压；日期选择器三列文字不换行；日历金额不溢出；图例金额不与名称重叠。
- 420vp 下：卡片不被拉得过于稀疏；图表不拉伸变形（保持最大宽度或等比）。
- 横屏不在 v1 范围，锁竖屏（`module.json5` 的 `orientation: portrait` 如需）。

### 5.2 字号与可读性

- 设计稿 7–9vp 的辅助文字已提升到 ≥10vp，逐页确认（日历、图例、设置副标题、图表轴）。
- 金额数字使用 tabular 数字，纵向对齐。
- 大号字体下：标题不截断、按钮文字不溢出；必要时对关键区域限制 `maxLines` + 省略。

### 5.3 深色模式

- 无白色卡片残留、无浅色文字压白底、无硬编码颜色。
- 主按钮在深色下为浅底深字；Hero 渐变、分类色、图表色与设计 §4 一致。
- 状态栏图标颜色随页面切换正确。
- 弹层遮罩、阴影不突兀（深色阴影更黑，但不应出现双层灰边）。

### 5.4 交互

- 所有图标按钮热区 ≥44×44（视觉 34，热区扩大）。
- 长按删除、5 秒撤销、返回拦截、下拉刷新、系统返回手势全部可用。
- 键盘弹起时，记一笔的保存按钮不被遮挡；备注编辑器在键盘上方。
- 页面切换无白屏、无闪烁；连续快速点按 Tab 不崩溃。

### 5.5 性能基线（中端真机）

| 指标 | 目标 | 测量方式 |
|---|---|---|
| 冷启动到首页可交互 | ≤ 2 秒 | 录屏/日志时间戳 |
| 首页列表滚动 | 无明显掉帧 | 目测/DevEco Profiler |
| 图表首次绘制 | ≤ 300ms | 日志时间戳 |
| 1000 笔数据下月份切换 | ≤ 500ms | 日志时间戳 |
| 内存占用 | 无持续增长（连续切页 20 次） | DevEco Profiler |

### 5.6 隐私

- 私密账本锁定态金额打码、统计排除。
- 防截屏在私密页面生效，退出后恢复。
- 备份包内私密账本金额/备注不可读。

## 6. 问题记录格式

`T25-report.md` 中按以下格式记录：

```text
## 问题 3
- 页面：预算页
- 设备：Mate 60 / 360vp 模拟器
- 现象：主预算卡在 360vp 下“每天可用”文字换行
- 严重度：中
- 修复：字号 10 → 9? 否，改为缩短文案“日均可用” + 单行省略
- 状态：已修复 / 待确认
```

严重度定义：`高`=功能不可用/数据错误；`中`=明显视觉偏差/操作受阻；`低`=细节瑕疵。

## 8. 注意事项

- 走查以真机为准，模拟器的模糊/阴影/字体渲染可能与真机不同。
- 截图对比只用于发现差异，不要求像素级一致；以设计规范的文字规格为准。
- 修复问题时不要破坏已通过的验收项；每次修复后重跑相关页面。
- 防截屏开启时无法截图，先关闭再截图记录。
