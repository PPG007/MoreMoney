## 3. 发布前仍需人工完成的事项

### 真机复核

- SAF 文件选择（CSV/备份导入导出）、厂商字体、横屏/折叠屏/多窗口。
- 至少一台 API 26–28 设备验证拼音降级与低版本行为。

### 正式发布

- 生成并离线保管正式 release keystore；创建本机 `keystore.properties`（不入库），用正式密钥重跑 T26.4 的安装/升级验证。
- Google Play：Data Safety、隐私政策 URL、内容分级；国内分发：软件著作权、App 备案。
- 商店图标 512×512、Feature Graphic 1024×500 等尺寸素材需美术导出。

### 仓库

- Git 仓库尚未初始化（WBS D6）；本次没有提交。如需按子任务提交需先 `git init`。
- 未添加 Jacoco；质量门禁以 JUnit + instrumentation + Lint + 红线脚本为准。

### 已知偏差 / 待打磨

- 统计页“天数”在隐藏金额时显示 `••`，属于保守处理。
- 日历热力图例在隐藏金额时统一中性色。
- 演示数据的备注与分类按索引随机组合，仅用于样式检查。
- CSV 导入允许任意 MIME（部分文件管理器把 `.csv` 报为 `application/octet-stream`），由表头与逐行校验兜底。
- 备份头部计数仅展示，校验以版本 + SHA-256 为主（兼容含私密账本的旧备份）。
- 360dp + 1.3× 下记账选择器值会省略，点击选择器可见完整值。
- 首页横屏首屏需要滚动，FAB 与摘要卡右下角轻微重叠；不影响操作。
