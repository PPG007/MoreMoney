# T14 · 全局金额隐藏覆盖

> 状态：待开始 ｜ 优先级：P2 ｜ 依赖：T05、T06、T12 ｜ 预估：1.0 人日
> 设计依据：`设计规范.md` §9.3、§2.4；截图 `20-home-hide-light.png`

## 1. 目标

把“眼睛按钮”从一个组件行为升级为全站一致的状态：任一页面切换后，所有页面同步；隐藏范围覆盖文本、进度条、图表、日历热力，且不能从图形反推金额。

## 2. 交付物

| 路径 | 内容 |
|---|---|
| 各页面 `EyeButton` 接入 | 首页、预算、图表（三子页）、搜索、账本管理、数据与备份 |
| `MoneyText` / `AmountBar` / `RingProgress` / 图表组件的 `hidden` 支持 | 统一由 `GlobalUiStore.hideAmount` 驱动 |
| `docs/tasks/T14-checklist.md`（可选） | 逐项走查记录，可并入本文 |

## 3. 隐藏范围清单

| 页面 | 必须隐藏 | 必须保持可见 |
|---|---|---|
| 首页 Hero | 无 | 账本名、月份、锁图标 |
| 首页摘要卡 | 本月支出、预算/已用/剩余、每天可用、进度条填充 | 标签文字、进度条轨道 |
| 首页流水 | 每笔金额、每日小计 | 分类图标、成员、备注、日期 |
| 预算页 | 三列数字、主卡三项、每天可用、其他账本金额/百分比/进度填充 | 账本名、图标、环轨道、环中心百分比（设计允许） |
| 图表·分类 | 中心总额、图例金额、图例占比（金额可反推） | 分类名、图标、颜色、扇区形状 |
| 图表·趋势 | 主数字、统计三列、最高点气泡金额、最高 3 天金额与条 | 日期轴、折线形状 |
| 图表·日历 | 每日金额、热力填充 | 日期数字、选中框 |
| 搜索 | 结果金额 | 备注/分类/成员/日期 |
| 账本管理 | 账本已用/剩余、进度填充 | 名称、徽标、笔数 |
| 数据与备份 | 数据统计里的总金额（若有） | 笔数、账本数、文件大小 |

规则：

1. 金额统一由 `MoneyText` 打码为 `¥••••`；不要在页面里各写一套。
2. 进度条/环形：隐藏填充，只留轨道；不显示百分比数字（预算环中心除外，见上表）。
3. 热力：隐藏填充色，保留日期格子。
4. 饼图/趋势：图形形状可保留，但不得显示任何金额与占比；中心改为 `¥••••`。
5. 分类占比标签（饼图扇区上的 `%`）在隐藏时一并隐藏，避免反推。

## 4. 实现要求

- 所有页面从 `UiStore.instance()` 读取 `hideAmount`，不各自维护本地开关。
- `EyeButton` 只调用 `ui.hideAmount = !ui.hideAmount`，不做页面级刷新；依赖 `@ObservedV2` 自动刷新。
- Canvas 图表在 `@Monitor('ui.hideAmount')` 或 `@Monitor('hidden')` 中触发重绘；不要只改 ArkUI 文本。
- 隐藏状态**不持久化**：冷启动恢复显示。
- 私密账本打码与全局隐藏叠加：任一条件满足即打码；`forceVisible` 只用于解锁弹层内的密码校验提示等特殊场景。

## 6. 注意事项

- 不要用 `blur` 或降低透明度代替打码：透明度仍可读，模糊在深色下会露底。
- 图表重绘要在数据或隐藏状态变化时都触发，避免出现“数字隐藏了但饼图还是旧标注”。
- 隐藏时保持布局尺寸稳定，避免整页跳动（预留 `¥••••` 宽度）。
