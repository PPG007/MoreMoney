## 3. 本轮发现并修复的问题

1. **首页摘要卡压住 Hero 内容**
   - 现象：摘要卡用 `offset` 上移后仍占据原布局高度，且按底部对齐时遮住月份与账本 chips。
   - 修复：`pullUp(54.dp)` 自定义 `Layout`，视觉上移同时收缩布局高度；账本 chips 与月份完整可见。
2. **状态栏图标颜色反了**
   - 现象：浅色二级页出现白色状态栏图标；首页 Hero 上出现深色图标。
   - 修复：`SystemBarAppearance(darkIcons)` 语义统一；Hero 用白色图标，其余页面深色图标。
3. **360dp + 1.3× 金额截断**
   - 现象：首页“预算/每天可用/剩余”显示为 `¥3,000.0`。
   - 修复：`MoneyText` 接入 `TextAutoSize.StepBased`，空间不足时自动缩小字号（最小 8sp）。
4. **Snackbar 撤销按钮被 FAB 压住**
   - 现象：删除后的“撤销”位于 FAB 下方，视觉与点击都受影响。
   - 修复：Snackbar 右侧预留 88dp；动作色按浅/深色反向取 token。
5. **横屏“记一笔”分类区高度为 0**
   - 现象：固定区域（键盘/选择器）占满高度，`weight(1f)` 的分类区被压成 0，无法选分类。
   - 修复：`BoxWithConstraints` 检测高度 < 520dp，切换为整页滚动布局；分类使用 8 列 `FlowRow`，键盘和保存可滚动到达。
6. **全屏二级页缺少底部 Insets**
   - 现象：键盘/底部内容可能被手势条遮挡。
   - 修复：记一笔、账本/分类管理、数据与备份、搜索页统一加 `navigationBarsPadding()`。

## 4. 已知限制

- 360dp + 1.3× 下“账本/日期”选择器值会省略（如“日常…”），点击后选择器里可见完整值；不涉及金额截断。
- 首页横屏首屏只能看到 Hero 与摘要卡的上半部分，需要滚动；FAB 与摘要卡右下角有轻微重叠，不影响操作。
- 未在真机验证：SAF 文件选择器、厂商字体、折叠屏/多窗口；建议 T26 发布前补一台 API 26–37 真机。
- 本报告中的窄屏/横屏系统设置已在验收后恢复默认。
