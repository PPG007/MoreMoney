# T23 · 删除撤销与状态反馈

> 状态：待开始 ｜ 优先级：P3 ｜ 依赖：T06、T07 ｜ 预估：1.0 人日
> 设计依据：`设计规范.md` §9.6

## 1. 目标

统一流水的删除与撤销、空态、加载骨架、失败提示与重试，避免每个页面各写一套。

## 2. 交付物

| 路径 | 内容 |
|---|---|
| `entry/src/main/ets/components/base/ConfirmSheet.ets` | 通用确认弹层/对话框封装 |
| `entry/src/main/ets/components/base/SkeletonList.ets` | 列表骨架屏 |
| `entry/src/main/ets/components/base/ErrorRetry.ets` | 失败重试块 |
| `entry/src/main/ets/pages/home/TxnRow.ets` | 增加长按菜单 |

## 3. 删除与撤销

### 3.1 交互

- 流水行**长按** 400ms → 底部动作菜单：`删除`、`取消`。
- 点击删除：
  1. `TxnDao.softDelete(id)`（写 `deleted_at`）；
  2. 列表立即移除该行，合计同步更新；
  3. `SnackBarService.show({ message: '已删除 1 笔', actionLabel: '撤销', durationMs: 5000, onAction: undo })`；
  4. 5 秒内点“撤销” → `TxnDao.restore(id)` 并刷新；
  5. 5 秒后不做额外写入（行已软删），由清理任务处理。
- 不弹二次确认（有 5 秒撤销即可），与设计一致。
- 删除私密账本流水需已解锁。

### 3.2 过期清理

- `DeleteService.purgeExpired()`：删除 `deleted_at < now - 30 天` 的流水；在 `Index.aboutToAppear` 中触发一次，失败不阻断启动。
- 撤销后又删除的，以最后一次 `deleted_at` 为准。

## 4. 状态

### 4.1 加载骨架

- 首页：Hero 下方 2 个灰色卡片块（高度 120）+ 3 行列表骨架（42 圆 + 两行文字）。
- 预算页：三列卡 + 主卡 + 2 行。
- 图表页：图表卡位置一个 280 高的圆角块。
- 骨架颜色 `surface_2`，做 1.2s 透明度呼吸动画（可选，若实现需保证不闪烁）。
- 数据加载完成前不显示“空状态”。

### 4.2 失败

- 页面级加载失败：内容区显示 `ErrorRetry`（图标 `ic_warning`、文案“加载失败”、次级按钮“重试”），保留 Hero/头部。
- 写入失败：`SnackBar` 错误文案 + 不关闭当前面板（记一笔保存失败时保留输入）。
- 不在页面中间弹全屏错误图。

### 4.3 空态

统一使用 `EmptyState`：

| 场景 | 文案 |
|---|---|
| 首页无流水 | 本月还没有记账 / 点右下角 + 记一笔 |
| 搜索无结果 | 没有找到相关记录 / 试试备注、分类或成员名 |
| 预算全空 | 还没有预算 / 先给一个账本设置月度预算 |
| 图表无数据 | 这个周期还没有支出 / 换个周期试试 |
| 分类为空 | 还没有分类 / 新建一个分类开始记账 |
| 成员为空 | 至少保留一位成员（不出现空态） |

## 5. 表单校验反馈

- 输入超长：输入框下方 10/400 `expense` 提示（如“最多 12 个字”）。
- 必填未填：保存按钮禁用 + 点击时 `SnackBar` 提示，不弹红框。
- 金额非法：沿用计算器预览文案，不额外弹窗。
- 所有提示文案集中放在 `resources/base/element/string.json`（或统一常量文件），不散落硬编码。

## 6. 验收标准

| 编号 | 验收项 | 验证方式 |
|---|---|---|
| AC-1 | 长按流水 400ms 出现删除菜单，点击删除后行消失、合计更新 | 真机 |
| AC-2 | 5 秒内点撤销，记录恢复且回到原位置 | 真机 |
| AC-3 | 超过 5 秒未撤销，重启应用后记录仍不出现 | 真机 |
| AC-4 | 软删 30 天以上的数据在启动时被清理（可改阈值测试） | 代码审查/临时改常量 |
| AC-5 | 首页/预算/图表首次进入显示骨架，数据到达后替换，无闪烁 | 真机（弱网/大数据） |
| AC-6 | 模拟 DAO 抛错时显示重试块，点击重试可恢复 | 异常注入 |
| AC-7 | 记一笔保存失败时面板不关闭且输入保留 | 异常注入 |
| AC-8 | 各页面空态文案统一，无空白卡片 | 真机 |
| AC-9 | 构建通过 | `devecocli build` |

## 7. 注意事项

- 撤销只对“最近一次删除”有效；连续删除时以最新一条为准，旧提示被替换。
- 软删数据必须继续参与“已删除”判定，不能被统计查询误算。
- 骨架屏不要引入第三方库，用普通容器 + 圆角块即可。
- 删除菜单用 ArkUI 原生 `bindMenu` 或自定义 `bindSheet`，不要自造浮层导致点击穿透。
