设计原则

  • 预算先于流水打开先看本月还剩多少，再看每一笔。
  • 单手记一笔分类在上、键盘在下；金额支持加减乘除。
  • 隐私是一等状态私密账本在列表里就遮住金额。
  • 流水可改可删点击编辑，左滑删除；删除后 5 秒内可撤销。
设计系统

柔和，但不含糊

靛蓝负责情绪，墨色负责信息；预算绿和压力红只在需要判断时出现。图表色经过相邻色对校验，图例同时给出名称、比例和金额，不依赖颜色单独传达信息。

色彩

品牌靛强调 / 选中 / 进度
深靛顶部渐变 / 主按钮
页面底色随主题切换
预算绿剩余 / 安全
压力红支出金额
主文字正文 / 数字

图表分类色：蓝、橙、青、黄、品红，加中性灰的“其他”。浅色模式下青、黄、品红对比度低于 3:1，因此饼图直接标注比例，图例同时给出金额。

字体

Noto Sans SC 负责中文，Baloo 2 只用于金额和关键数字。金额使用等宽数字，列表、预算和图表之间纵向对齐。

形状

预算 64%

24px 卡片、16px 内块、999px 胶囊。阴影只给需要浮起的摘要卡、预算卡和 FAB；列表用发丝线分隔，保持安静。

鸿蒙落地

  • 结构Tabs + Navigation + List / Grid；四个一级页，记账与私密解锁用全屏面板。
  • 数据RDB 以整数分存储金额，UUID 主键，软删除；索引日期、账本、成员、分类。
  • 隐私userAuth 生物识别、Asset Store 保存密钥、窗口隐私模式防截屏。
  • 备份加密备份包 + 系统文件选择器 / 网盘，WorkScheduler 定时触发。
  • 图表Canvas 自绘饼图、折线和日历热力，避免第三方图表库的样式限制。
